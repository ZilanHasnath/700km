# 300km

A full stack luxury helicopter marketplace and booking platform built with Next.js and MongoDB.

### Tech Stack
* **Frontend:** Next.js, React, Tailwind CSS, TypeScript
* **Backend:** Node.js, Express, Mongoose, MongoDB
* **Integrations:** Stripe (Payments), Nodemailer (Auth & Recovery), Google OAuth

### Features
* Google Sign-Up & Password Reset via Nodemailer
* Dynamic Cart & Direct "Buy Now" Checkout
* Secure Stripe Payment Gateway
* Comprehensive Admin Panel for Management
